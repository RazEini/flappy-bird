🕹️ Flappy Bird App

Mobile game – a Jetpack Compose implementation of the classic Flappy Bird game.

🚀 Features

Tap to make the bird jump

Dynamic obstacles (pipes) with random heights

Score tracking & high score system

Multiple lives & invincibility frames on hit

Start screen, gameplay, and game over screen

Animated bird sprite

Simple physics with gravity and jump mechanics

🛠️ Tech Stack

Kotlin • Android Studio • Jetpack Compose • Material3
